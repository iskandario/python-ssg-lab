# Проверка результата

После развёртывания сайт следует проверить не только визуально.

## HTTP-код

```bash
curl -I https://iskandario.github.io/python-ssg-lab/
```

Ожидаемый результат: `HTTP/2 200` или `HTTP/1.1 200 OK`.

## Контрольная строка

```bash
curl -fsSL https://iskandario.github.io/python-ssg-lab/ \
  | grep -F 'SSG-LAB-CONTROL-2026'
```

Наличие строки подтверждает, что опубликована актуальная версия сайта.

## Поиск

Встроенный плагин `search` формирует индекс локально во время сборки. Проверка: в поле поиска ввести `контрольная строка` или `Helios` и убедиться, что соответствующая страница находится.

## Формулы без CDN

Формулы в проекте записаны нативным MathML. Внешние JavaScript- или CSS-ресурсы для них не нужны, поэтому блокировка внешних CDN не влияет на отображение математических выражений в браузерах с поддержкой MathML.

## Проверка относительных ссылок

Строгая сборка запускается так:

```bash
mkdocs build --strict
```

Если MkDocs обнаружит предупреждение, CI завершится с ошибкой и публикация не будет выполнена.
