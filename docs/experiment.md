# Публикация результатов эксперимента

Для демонстрации возможностей SSG используется небольшой воспроизводимый пример: измерение времени сборки условного проекта при разном количестве входных Markdown-файлов.

| Число страниц | Время сборки, с | Размер сайта, КБ |
| ---: | ---: | ---: |
| 10 | 0.18 | 310 |
| 50 | 0.41 | 690 |
| 100 | 0.79 | 1180 |

> Значения приведены как демонстрационные данные для оформления исследовательского материала. В реальном эксперименте таблица должна формироваться из фактических измерений.

## Представление результата

Для серии измерений среднее значение можно записать как:

<math display="block" xmlns="http://www.w3.org/1998/Math/MathML">
  <mrow>
    <mover><mi>t</mi><mo>¯</mo></mover>
    <mo>=</mo>
    <mfrac>
      <mrow><munderover><mo>∑</mo><mrow><mi>i</mi><mo>=</mo><mn>1</mn></mrow><mi>n</mi></munderover><msub><mi>t</mi><mi>i</mi></msub></mrow>
      <mi>n</mi>
    </mfrac>
  </mrow>
</math>

Преимущество такого подхода — данные, пояснения, кодовые фрагменты и формулы находятся рядом и версионируются вместе с проектом.
