# Исследование генераторов статических сайтов на Python

## Почему выбран MkDocs

MkDocs ориентирован на документацию и исследовательские материалы: исходники пишутся в Markdown, конфигурация хранится в одном YAML-файле, есть локальный сервер предпросмотра, встроенный поиск и детерминированная генерация статического HTML.

Среди альтернатив на Python можно выделить Sphinx, Pelican и Nikola. Sphinx особенно силён в технической документации и API-справочниках, Pelican — в блогах и публикациях, Nikola — в более гибких контентных сайтах. Для лабораторной MkDocs выбран из-за минимальной конфигурации и прозрачной CI/CD-схемы.

## SSG и Jamstack

При использовании SSG сервер не генерирует страницы на каждый HTTP-запрос. HTML, CSS, JavaScript и поисковый индекс создаются заранее на этапе сборки. Это упрощает хостинг, уменьшает поверхность атаки и позволяет публиковать сайт на любой площадке, способной раздавать статические файлы.

## Фиксация зависимостей

В `requirements.txt` указаны точные версии:

```text
mkdocs==1.6.1
virtualenv==20.35.3
```

Это уменьшает риск того, что новая версия пакета изменит поведение сборки без изменения исходного кода проекта.
