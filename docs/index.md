<div class="hero">

</div>

## Цель

Исследовать генераторы статических сайтов (SSG) на Python как инструмент публикации результатов экспериментов и сопровождающих исследовательских материалов, а также освоить автоматизацию сборки и развёртывания сайта средствами CI/CD.

## Что реализовано

- исходные материалы хранятся в Markdown;
- зависимости закреплены точными версиями;
- локальная и CI-сборка выполняется в строгом режиме;
- настроена публикация на GitHub Pages через официальный Pages workflow;
- подготовлен workflow развёртывания на сервер Helios по SSH/rsync;
- используется встроенный локальный поиск MkDocs;
- математическая формула выводится без внешнего CDN;
- код и контент лицензируются раздельно.
