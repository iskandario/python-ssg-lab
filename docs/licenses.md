# Лицензии

Лицензирование разделено на две части.

## Код

Исходный код проекта, конфигурационные файлы и workflow GitHub Actions распространяются по лицензии MIT. Текст лицензии находится в корне проекта в файле `LICENSE`.

## Контент

Текстовые исследовательские материалы в каталоге `docs/` распространяются по лицензии Creative Commons Attribution 4.0 International (CC BY 4.0). Условия указаны в `CONTENT_LICENSE.md`.

Такое разделение позволяет отдельно регулировать повторное использование программного кода и авторских материалов.
